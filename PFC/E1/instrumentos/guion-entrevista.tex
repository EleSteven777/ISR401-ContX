\medskip
El guion no sustituye al consentimiento firmado. En esta sesi\'on no se realizan videos,
fotograf\'ias, observaciones del trabajo ni cuestionarios.

\subsection*{Prop\'osito y t\'ecnica}
Conocer c\'omo funciona el taller y c\'omo se atiende un servicio de reparaci\'on, para identificar
necesidades, participantes, prioridades y restricciones. No se da por confirmado ning\'un problema
ni se propone un alcance de software antes de escuchar y validar la informaci\'on.

Se utiliza una entrevista semiestructurada porque el responsable puede explicar sus tareas,
decisiones y expectativas con sus propias palabras, y el entrevistador puede profundizar en
ejemplos. La fuente es su experiencia en la gesti\'on del taller; se busca principalmente
conocimiento que pueda expresar verbalmente. Los aspectos dif\'iciles de explicar o las versiones
contradictorias se registran para validarlos con otra fuente o t\'ecnica.

\subsection*{Indicaciones para quien entrevista}
\begin{itemize}[nosep]
  \item Formular una pregunta a la vez, escuchar y no sugerir respuestas.
  \item Las repreguntas son opcionales; si un tema ya fue respondido, confirmar lo entendido.
  \item No presentar como hechos los antecedentes comentados antes de la entrevista.
  \item Pedir ejemplos sin nombres, tel\'efonos ni informaci\'on identificable de clientes; no
        solicitar credenciales, contenido privado de equipos ni datos bancarios.
  \item Distinguir lo dicho por el participante de las conclusiones del equipo; anotar si una
        cifra es un registro, una estimaci\'on o una opini\'on. No inventar valores.
\end{itemize}

\subsection*{Apertura (5 min)}
\begin{enumerate}[nosep]
  \item Presentar a quienes entrevistan y toman notas.
  \item Entregar y explicar el consentimiento; la persona lo lee, marca sus decisiones y firma.
  \item Comprobar las opciones a, b y c sin marcarlas por el participante.
  \item Confirmar el tiempo disponible y explicar el prop\'osito de la conversaci\'on.
\end{enumerate}

\subsection*{A. Organizaci\'on y participantes (5 min)}
\begin{description}[style=nextline,leftmargin=0.6cm,font=\normalfont\bfseries]
  \item[A1. ?`Cu\'al es su funci\'on en JC\textbar{}cell?] Repregunta: ?`qu\'e decisiones toma como parte de esa funci\'on?
  \item[A2. ?`Qu\'e servicios ofrece actualmente el taller?] Repregunta: ?`desde hace cu\'anto funciona el taller?
  \item[A3. ?`C\'omo se distribuyen las tareas entre las personas que trabajan en el taller?] Repreguntas: ?`cu\'antas personas trabajan habitualmente?, ?`qu\'e tarea realiza cada persona? (sin nombres).
  \item[A4. ?`Con qui\'enes se comunica normalmente para coordinar una reparaci\'on?] Repreguntas: ?`para qu\'e se comunica con cada uno?, ?`qu\'e informaci\'on necesita recibir de ellos? (por roles).
\end{description}

\subsection*{B. Recorrido de un servicio (20 min)}
\begin{description}[style=nextline,leftmargin=0.6cm,font=\normalfont\bfseries]
  \item[B1. ?`Podr\'ia contar c\'omo atendieron una reparaci\'on reciente, desde que recibieron el equipo hasta que lo entregaron?] Caso real sin identificar al cliente.
  \item[B2. ?`Qu\'e hacen cuando reciben un equipo para reparaci\'on?] Repreguntas: ?`qu\'e informaci\'on registran?, ?`d\'onde?, ?`c\'omo identifican cada equipo?, ?`c\'omo saben d\'onde est\'a guardado?
  \item[B3. ?`C\'omo determinan qu\'e trabajo necesita el equipo?] Repreguntas: ?`c\'omo calculan el precio?, ?`c\'omo lo explican?, ?`c\'omo confirma el cliente?, ?`qu\'e hacen si no acepta?
  \item[B4. ?`C\'omo conocen el avance de cada reparaci\'on?] Repreguntas: ?`qu\'e etapas sigue un equipo?, ?`qui\'en registra los avances?, ?`c\'omo se entera otra persona del estado?
  \item[B5. Cuando una reparaci\'on necesita una pieza, ?`qu\'e pasos siguen para conseguirla?] Repreguntas: ?`c\'omo saben qu\'e repuestos tienen?, ?`c\'omo registran las piezas usadas?, ?`qu\'e hacen si no est\'a disponible?
  \item[B6. ?`C\'omo se comunican con el cliente durante el servicio?] Repreguntas: ?`en qu\'e momentos?, ?`c\'omo saben si recibi\'o el mensaje?, ?`qu\'e hacen si no responde?
  \item[B7. ?`C\'omo gestionan el cobro de un servicio?] Repreguntas: ?`d\'onde anotan el pago?, ?`c\'omo comprueban pagos pendientes?, ?`qu\'e comprobante entregan? (sin datos bancarios).
  \item[B8. ?`C\'omo realizan la entrega del equipo al cliente?] Repreguntas: ?`qu\'e comprueban antes?, ?`c\'omo dejan constancia?, ?`qu\'e hacen si el cliente regresa por la misma reparaci\'on?
\end{description}

\subsection*{C. Fortalezas, dificultades y evidencia (10 min)}
\begin{description}[style=nextline,leftmargin=0.6cm,font=\normalfont\bfseries]
  \item[C1. ?`Qu\'e partes de este proceso funcionan bien y convendr\'ia conservar?] \mbox{}
  \item[C2. ?`En qu\'e partes del trabajo, si las hay, encuentra dificultades?] Si no reporta dificultades, pasar a C4.
  \item[C3. Sobre una de las dificultades que mencion\'o, ?`podr\'ia describir un caso reciente?] Repreguntas: qu\'e ocurri\'o, c\'omo se resolvi\'o, a qui\'enes afect\'o, con qu\'e frecuencia y en qu\'e per\'iodo, si la frecuencia est\'a registrada o es estimada, consecuencias y registro que permitir\'ia comprobarlo.
  \item[C4. Si pudiera mejorar un solo aspecto del trabajo, ?`cu\'al elegir\'ia primero?] Repregunta: ?`por qu\'e lo considera prioritario?
\end{description}

\subsection*{D. Resultados esperados y condiciones (10 min)}
\begin{description}[style=nextline,leftmargin=0.6cm,font=\normalfont\bfseries]
  \item[D1. ?`C\'omo se dar\'ia cuenta de que la mejora que propone est\'a funcionando?] Repreguntas: qu\'e cambiar\'ia en el trabajo diario, qu\'e podr\'ia comparar, si existe un registro para comparar.
  \item[D2. ?`Con qu\'e recursos cuentan actualmente para organizar el trabajo?] Repreguntas: aplicaciones o sistemas, equipos disponibles, conexi\'on a Internet.
  \item[D3. ?`Qu\'e condiciones deber\'ian respetarse al plantear una mejora?] Repreguntas: limitaciones de tiempo, recursos o presupuesto (sin montos), actividades que deben continuar y actividades fuera del proyecto.
  \item[D4. ?`A qui\'enes convendr\'ia consultar para entender mejor el trabajo del taller y revisar una propuesta de mejora?] Repreguntas: qu\'e necesitar\'ia cada uno, qui\'en decide, disponibilidad.
\end{description}

\subsection*{E. Cierre (5 min)}
\begin{description}[style=nextline,leftmargin=0.6cm,font=\normalfont\bfseries]
  \item[E1. ?`Qu\'e deber\'iamos corregir o completar de este resumen?] Resumir antes el proceso y las necesidades expresadas.
  \item[E2. ?`Hay alg\'un tema importante que no hayamos tratado?] \mbox{}
  \item[E3. ?`C\'omo podr\'iamos verificar la informaci\'on que qued\'o pendiente?] Acordar, solo si acepta, c\'omo revisar el resumen; registrar la hora de finalizaci\'on.
\end{description}
