La huella SHA-256 permite comprobar que el archivo original no fue modificado. Se calcula con:

```powershell
# Windows (PowerShell)
Get-FileHash -Algorithm SHA256 -LiteralPath "RUTA_DEL_ARCHIVO"
```

```bash
# Linux / macOS / Git Bash
sha256sum archivo.pdf
```
